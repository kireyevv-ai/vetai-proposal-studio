# VETAI Proposal Studio

Учебный AI-конструктор коммерческих предложений для сервисной компании.
Сценарий: бриф → проверка обязательных полей → генерация черновика через AI →
ручное редактирование → экспорт PDF → история КП.

> **Текущий этап:** каркас приложения, база данных SQLite, форма брифа и
> настройки (прайс услуг и шаблон КП). Генерация через AI, редактор, экспорт PDF
> и история КП ещё **не реализованы** — соответствующие экраны явно сообщают о
> своём статусе.
> Используйте только обезличенные учебные данные.

---

## Требования

- Python 3.10+
- pip

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
```

Скопируйте `.env.example` в `.env` и при необходимости заполните значения.
Реальные API-ключи в репозиторий не добавляются. На текущем этапе ключи не нужны:
GigaChat API подключается на следующем этапе.

## Запуск

```bash
streamlit run app.py
```

Приложение откроется в браузере. Навигация в боковой панели: четыре экрана ТЗ —
**Бриф**, **Черновик**, **Предпросмотр и PDF**, **История КП** — и служебный
экран **Настройки** (прайс услуг и шаблон КП).

Порядок работы: в разделе «Настройки» добавьте услуги и цены, затем заполните
бриф — услуги в нём выбираются из прайса.

## Структура проекта

```
app.py                        # точка входа Streamlit
vetai/
  config.py                   # пути и переменные окружения
  db.py                       # соединение с SQLite, схема и безопасные миграции

  models.py                   # модели (Brief, PriceItem, Template, ...)

    brief_repository.py       # сохранение и чтение брифов
    price_repository.py       # прайс: цены в копейках, архив, безопасное удаление
    template_repository.py    # шаблон КП: единый активный, обязательные разделы
  ui/
    navigation.py             # навигация между экранами
    screens/

      draft.py                # экран «Черновик» (статус: в разработке)
      preview.py              # экран «Предпросмотр и PDF» (статус: в разработке)
      history.py              # экран «История КП» (статус: в разработке)
tests/
  conftest.py
  test_validation.py
  test_money.py               # разбор/формат цены в копейках
  test_brief_repository.py
  test_price_repository.py
  test_template_repository.py
  test_db_migration.py        # безопасная миграция цены NUMERIC -> копейки
  test_app_navigation.py
  test_settings_screen.py
docs/                         # проектная документация
prompts/                      # проект системного промпта
```

## Данные и приватность

- Брифы хранятся локально в SQLite (по умолчанию `data/vetai_proposal_studio.db`).
- Прайс и шаблон КП хранятся в тех же SQLite-таблицах; **цены — в копейках**
  (целыми числами, без float) и подставляются в КП программно, а не моделью.
- Услуги в брифе выбираются из активных позиций прайса (раздел «Настройки»);
  архивирование или удаление позиции не изменяет уже сохранённые брифы.
- Секреты хранятся только в переменных окружения (`.env`), который исключён из Git.
- Логи не должны содержать персональных данных.
